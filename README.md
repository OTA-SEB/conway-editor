# Conway Studio ∞

**An interactive editor for playing with Conway's Game of Life.**

🌐 **Play online:** https://ota-seb.github.io/conway-editor/

## What is this?

Conway Studio ∞ is a web-based editor for experimenting with **Conway's Game of Life**, a cellular automaton created by mathematician John Conway.

The idea is simple: draw patterns, start the simulation, and watch cells evolve according to a few simple rules.

The goal isn't to build a scientific tool, prove a revolutionary theory, or solve the mysteries of the universe. It's simply to **make playing with Conway's Game of Life fun**. LOL.

## How does it work?

The page is built using standard web technologies:

- **HTML:** Defines the page structure, buttons, controls, and the canvas where cells are drawn.
- **CSS:** Handles colors, layout, visual styling, and the interface's adaptation to smaller screens.
- **JavaScript:** Implements the editor logic, simulation, drawing tools, user interactions, and cell rendering.

Everything is contained in a single HTML file, including the structure, styles, and JavaScript code. The simulation runs directly in your browser, so no custom backend server is required.

### Features

- ▶️ Start and pause the simulation, or advance one step at a time.
- 🎲 Generate random cells and clear the board.
- 🖌️ Draw and erase cells using different brush sizes.
- 🪣 Fill regions.
- ▧ Select areas of the board.
- 📐 Draw lines, rectangles, and ellipses, either outlined or filled.
- 🎨 Change cell colors.
- 🧩 Place well-known patterns, including gliders, spaceships, and stable structures.
- 🔍 Zoom in, zoom out, and move around the board.
- 📋 Copy, paste, and work with patterns using the editor's own text-based format.

The board is designed to let you explore a space far beyond what's visible on your screen. You can pan and zoom to experiment with your creations.
